## What exists

Public repo `cloud-f1/jev-agent-kit` (MIT). Claude Code plugin that shortens long Bash output before the model sees it.

- **Native Mod** `hooks/register.ts` (TypeScript, loaded directly, no build) + pure core `core/*.ts`.
- **No Python hook any more** (retired by the user's decision on 2026-10-10). Claude Code 2.1.271 to 2.1.286 loads the plugin but it does nothing. Python (`jevkit/`, `jev.py`, `pyproject.toml`) is the optional maintainer/eval CLI (run with `uv`) and the parity reference for the TS core.
- `/jev status | doctor | readback <id>` commands; skills `skills/operate` (shipped) and `.claude/skills/release` (project only).
- Local release gate `scripts/release_check.py`; shared golden fixtures `tests/fixtures/golden.{json,ts}` generated by `scripts/gen_golden.py` from the Python reference core.
- Plugin settings (`userConfig`) in `/config`; precedence defaults < plugin settings < project file; key in secure storage.
- Tests: 56 Python (`uv run --no-project python -m unittest discover -s tests`, verified on 3.10 to 3.14) + 69 Mod/core (`claude plugin test`). No CI (no quota); the gate is local.

## Verified, and what is NOT

Verified live (Claude Code 2.1.295, `claude -p --model haiku`, scratch project): module loads alone (`Registered 0 hooks`; the Python hook no longer exists), 30,000 → 570 chars, model received the pruned text and the readback line, `/jev doctor` and `/jev status` work, state files `0600` / dirs `0700`, project hash equals Python's.

**Not verified:** the interactive `/config` screen and the sensitive-key prompt (only seen through `claude -p`), the live Jev API (no key was ever used; every Jev path is stub-tested), `/jev readback` live, interactive-session UI (status line, hot reload), Windows Windows on a real Windows machine, and above all **any cost or success-rate benefit**. Do not claim savings; the paired agent-task benchmark (`docs/EVALUATION.md`) has not been run and needs a budget decision from the user.

## Traps already hit (do not rediscover)

- `defaultEnabled: false` in `plugin.json` ⇒ a `--plugin-dir` load registers no module and no hooks. The gate rejects it.
- An installed copy plus `--plugin-dir` share the name `jev-agent-kit`; disable the installed one in scratch tests.
- `claude plugin test` cannot import `.json`; fixtures are mirrored to `.ts`.
- `$.fs.write` has no file mode; the Mod writes via `sh -c 'umask 077; ...'` with stdin.
- Claude Code caps Bash output near 30,000 chars before hooks run.
- The release gate once silently skipped its secret scan because an edit deleted `return files`; a test now covers it. Secret-shaped fakes are allowed only under `tests/` and `scripts/gen_golden.py`.
- Installed plugins are cached by version: bump version (3 places + CHANGELOG) for anything users must receive.

## Independent audit (done 2026-10-10)

13 findings (1 high: redaction let Bearer/JSON-quoted secrets reach the Jev API). All fixed with regression tests; summary in `CHANGELOG.md`. Residual risks the auditor could not settle: `$.http.fetch` may follow redirects (the Authorization header is only ever sent to the fixed endpoint).
